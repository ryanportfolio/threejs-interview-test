# Commands

```sh
npm install       # install deps (three pinned 0.185.1)
npm run dev       # Vite dev server (default http://localhost:5173)
npm run build     # tsc --noEmit && vite build  <- the authoritative check
npm run preview   # serve the production build
```

No test runner and no linter are configured; `npm run build` plus a clean browser console is the whole verification story.
